# String-Diagram-Studio-for-Graphical-Calculus
This is a Web App in the style of https://q.uiver.app/ usable for graphical calculus. Create your diagram and export the code for Latex. If you are working with diagrammatics, just clone the repositpry and adjust it for your needs. This is a joint work with Malena Mancebo Mann, realized with help from Copilot and inspiration from Simon Lentner.
