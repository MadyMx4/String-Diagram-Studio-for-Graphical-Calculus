This is a Web App in the style of https://q.uiver.app/ usable for graphical calculus. Create your diagram and export the code for LaTeX or save your work as a JSON file. The commands needed to run the LaTeX code can be downloaded in the web app. 

If you are a mathematician working with diagrammatics, feel free to clone the repositpry and adjust it for your needs. 

This is a joint work with Malena Mancebo Mann, realized with help from Github Copilot and drew inspiration from the diagrammatics of Simon Lentner, which can be found e.g. on https://arxiv.org/abs/2311.14221.
