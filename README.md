# String-Diagram-Studio-for-Graphical-Calculus
This is a Web App in the style of https://q.uiver.app/ usable for graphical calculus. Create your diagram and export the code for Latex. If you are working with diagrammatics, just clone the repositpry and adjust it for your needs. This is a joint work with Malena Mancebo Mann, realized with help from Copilot and inspiration from Simon Lentner.


The code for the app is contained in the index.html file. 
The commands needed to run the LaTeX code are to be found in the diagram-output-template.tex file. This file can also be used as a testing ground for the exported LaTeX code.

The last feature added is the lowering / elevating of selected line segments. This part has not been reviewed yet and might not function in a satisfactory way.
