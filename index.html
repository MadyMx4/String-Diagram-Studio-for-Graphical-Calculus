This standalone file includes the support commands and the current diagram. Strand commands begin with [optional TikZ style]{line width in pt}{color}: use \dLine for straight strands, \sLine or \hLine for smooth strands, \dCup or \dCap for same-row cups/caps, and \dMult for multiplications. Use \dLMult or \dRMult only when the target shares the left or right source's x position. Add O to a strand command for its white crossing underlay; \dBull draws a colored point.
